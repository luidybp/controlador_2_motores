# Projeto de um controlador sensorless microcontrolado para 2 motores CC com alimentação 180 Vcc 

- STM32F411
- Compilador Arm GNU Toolchain
- Cmake
- STlink
- Ninja


- A pasta Gerador PWM é apenas um código teste para gerar sinais em dois canais PWM e um botão que altera a frequência do PWM
- A pasta TCC é efetivamente o código completo
